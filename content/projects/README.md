# Projects

Add one file or folder per project, or paste a collection here.

Suggested format for each project (`project-name.md`):

```md
# Project Name

**Role:** …  
**Stack:** …  
**Links:** demo / GitHub / paper

## Summary
1–3 sentences on what it is and why it matters.

## Highlights
- Impact / result
- Technical challenge solved
- What you owned

## Media
- Screenshot paths or URLs
```

Collection docs, pitch decks, or notes from past projects are fine too — dump them here and we’ll organize later.
